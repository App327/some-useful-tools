# Очистка журналов KSWEB

Этот простой инструмент позволит очистить логи [KSWEB](https://play.google.com/store/apps/details?id=ru.kslabs.ksweb) с помощью PHP.

## Причины создания инструмента

### ❌ Проблема

В KSWEB есть функциональность очистки журналов компонентов, но когда в журнале становится слишком много записей, интерфейс просмотра содержимого журналов зависает. А кнопка «Очистить» расположена как раз на странице просмотра содержимого журналов.

Поэтому, через приложение очистить большие журналы очень сложно.

### ✅ Решение

С помощью PHP (запущенного в KSWEB) можно получить доступ к содержимому папки KSWEB, в том числе и к файлам журналов компонентов.

Поэтому, я и сделал этот простой инструмент. Надеюсь, он кому-нибудь будет полезен :)

## Файлы инструмента

* **[clearKSWEBLogs.php](/clear-ksweb-logs/clearKSWEBLogs.php)** — основной файл инструмента. Именно его и нужно запускать, чтобы очистить логи в KSWEB.

## Функциональность инструмента

* Очистка журналов компонентов KSWEB:
    * Lighttpd
    * Nginx
    * Apache
    * MySQL
    * PHP
    * MSMTP
    * Планировщик
* Отображение текущей версии PHP

## Идеи для дальнейшего расширения инструмента

* Отображение содержимого журналов (в веб-интерфейсе).
* Полноценный интерактивный HTML-интерфейс.
* Отображение размеров журналов перед очисткой.
* Частичая очистка только определённых записей в журналах (например, по регулярным выражениям).

## Проверка работы инструмента

Работа этого инструмента проверена в следующих условиях:

* KSWEB 3.988
* Apache
* PHP 8.2.6
* Android 14 (HyperOS 1.0.8.0)

Обратите внимание, что в других условиях инструмент может работать некорректно.

## Важная информация

Этот инструмент нужно запускать через установку KSWEB, журналы компонентов которой требуется очистить.

Для работы данного инструмента root-права не нужны.
