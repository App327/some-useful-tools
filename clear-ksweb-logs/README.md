# Очистка журналов KSWEB

Этот простой инструмент позволит очистить логи KSWEB с помощью PHP.

## ❌ Решение

В KSWEB есть функциональность очистки журналов компонентов, но когда в журнале становится слишком много записей, интерфейс просмотра содержимого журналов зависает. А кнопка «Очистить» расположена как раз на странице просмотра содержимого журналов.

Поэтому, через приложение очистить большие журналы очень сложно.
